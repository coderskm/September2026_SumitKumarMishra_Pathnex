2. drwxr-xr-x@ -> 
here d means directory
@ denotes metadata which means it has stored information about data somewhere in cache

3. xattr command -> used to check metadata about a file or folder eg :- xattr filename
 
4. -rw-r--r-- ->
divide this into three parts :-
1> rw- :- owner -> 4+2 = 6
2> r-- :- group -> 4
3> r-- :- other -> 4

owner is someone who creates file or folder

r represents Read (4) , w represents Write (2) and x represents Execute (1)

5. Permissions 0644 are too open :- here 0 represents octal notation 

6. Examples :- 
1> chmod 400 linux-server.pem
2> chmod -rwxrw-r-- info.txt
3> chmod u=r,g=0,o= tether.pem

21. link ->
1> Its like creating a pointer to access a file at some other location.
2> two types :- soft link and hard link
3> also known as symbolic link

4> in soft link if original file is deleted then link is broken
5> command :- ln -s org-file/org-file-path org-file-link-name
6> Example :-
command :- ln -s placeholder_demo/multi/dir-1/dir-2/dir-3/og-text-file.txt og-text-file-short-link
O/P :- lrwxrwxrwx. 1 ec2-user ec2-user  57 Sep  3 07:23 og-text-file-short-link -> placeholder_demo/multi/dir-1/dir-2/dir-3/og-text-file.txt

7> in hard link if original file is deleted or renamed then link is not broken so its useful for backup
8> command :- ln org-file/org-file-path org-file-link-name

<ii> RELATIVE --> projects/website/index.html
